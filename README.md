An enterprise-grade **AI CRM Governance & Security Portal** enforcing strict **Zero-Trust Policy Enforcement (PDP)** around LLM Tool Calling.

This platform addresses **Problem Statement PS-2.2 (Permission Enforcer Proxy for AI Customer Assistant)** by placing an immutable governance gateway between natural language LLM intent extraction and downstream CRM API execution.

---

## Key Security & Architectural Features

* **Zero-Trust Permission Proxy (PDP)**: Every tool request generated by the LLM is intercepted and evaluated against role-based scope manifests (`manifest.json`) prior to database execution.
* **Session Scope Isolation**: Enforces dynamic `session_customer_only` access control, preventing users from accessing or modifying records outside their authorized session ID.
* **Probing Threat Alerting**: Real-time detection mechanism identifying potential unauthorized probing behavior (automatically triggers security alerts after 3+ failed policy checks in a session).
* **Dual Execution Modes**:
  * **Google Gemini 2.0 / 1.5 Integration**: Uses Google's generative model for tool calling intent extraction and natural language response synthesis.
  * **Deterministic NLP Fallback Engine**: Guarantees 100% execution reliability even without an active API key or during network/rate-limit events.
* **Humanized Natural Language Responses**: Translates technical policy denials into polite, natural, professional English without exposing raw code terms or agent variable names.
* **Immutable Audit Observability**: Complete, real-time audit log stream tracking all evaluation decisions, execution latencies, and security alerts.

```mermaid
        IntentExtractor --> PDP{Permission Proxy PDP\n(manifest.json & Session Scope)}
        
        PDP -- Blocked (Out of Scope / Unauthorized) --> AuditBlocked[Audit Logger]
        AuditBlocked --> AlertService[Security Alerting Service]
        AlertService --> NLGenBlocked[Natural Language Generator]
        
        PDP -- Allowed --> CRMDB[(Mock CRM SQLite Database)]
        CRMDB --> AuditAllowed[Audit Logger]
        AuditAllowed --> NLGenAllowed[Natural Language Generator]
    end
    
    NLGenBlocked --> API
    NLGenAllowed --> API
```

## Local Setup & Quickstart

### Prerequisites

* Python 3.11 or higher
* Git

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RagaShuruthi/Aivar.git
   cd Aivar
   ```

2. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the project root (optional if using Deterministic NLP Fallback):
   ```env
   GEMINI_API_KEY="your_google_gemini_api_key_here"
   ```

4. **Launch the Application**:
   Run the unified local server runner:
   ```bash
   python run_all.py
   ```

5. **Access the Interfaces**:
   * **Streamlit UI Dashboard**: `http://localhost:8501`
   * **FastAPI Interactive Docs**: `http://localhost:8000/docs`

## Production Deployment on AWS (EC2 & Docker Compose)

### 1. Launch AWS EC2 Instance

* **Instance Type**: `t3.small` or `t3.medium`
* **Operating System**: **Ubuntu 24.04 LTS** or **Ubuntu 22.04 LTS**
* **Security Group Inbound Rules**:
  * Port `22` (SSH)
  * Port `8000` (FastAPI Backend)
  * Port `8501` (Streamlit Frontend UI)

### 2. Run Automated 1-Click Deployment

Connect to your EC2 instance via SSH and run:

```bash
git clone https://github.com/RagaShuruthi/Aivar.git
cd Aivar

# Set your optional Gemini API key
export GEMINI_API_KEY="your_api_key_here"

# Execute 1-click deployment script
chmod +x deploy_aws.sh
./deploy_aws.sh
```

    ```json

      "agent_role": "support_agent",

      "session_customer_id": 101
    ```

* `GET /api/v1/audit-logs?limit=100`
